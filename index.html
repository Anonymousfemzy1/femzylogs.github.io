Programmatic Orders

POST an order via script and receive fulfillment data in the response. No UI required.

place_order.js — FEMZY LOGS API
// Place an order via the Reseller API

const response = await fetch(
  "https://api.femzylogs.com/v1/orders",
  {
    method: "POST",
    headers: {
      "X-API-Key": process.env.FEMZY_API_KEY,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      product_id: "prod_xyz123",
      quantity: 5
    })
  }
);

const { order_id, status, items } = await response.json();

console.log(`✅ Order ${order_id} — ${status}`);
